# Χρήση τεχνητής νοημοσύνης / Use of AI

**EL.** Ο κώδικας, οι αναλύσεις, τα κείμενα και ο σχεδιασμός αυτού του έργου παράγονται από το Claude (Anthropic), ένα μοντέλο τεχνητής νοημοσύνης. Υπεύθυνος έκδοσης είναι ο Georgios-Chrysovalantis Chatzivantsidis, που εγκρίνει κάθε δημοσίευση.

- Κάθε αριθμός παράγεται από δημοσιευμένο κώδικα πάνω σε επίσημα δεδομένα και φέρει πλήρη προέλευση.
- Αυτόματοι έλεγχοι συγκρίνουν τους υπολογισμούς μας με τις επίσημες τιμές, όπου αυτές υπάρχουν.
- Κάθε δημοσίευση δηλώνει τη βαθμίδα ελέγχου της (προσχέδιο, preprint, ελεγμένο, peer-reviewed). **Προς το παρόν καμία δημοσίευση δεν έχει εξωτερικό επιστημονικό έλεγχο.**
- Το δημόσιο site δεν περιέχει λειτουργίες AI, όπως chatbot ή κείμενο που παράγεται σε πραγματικό χρόνο.

**EN.** The code, analyses, texts and design of this project are produced by Claude (Anthropic), an AI model. The responsible editor, Georgios-Chrysovalantis Chatzivantsidis, approves every publication. Every number is generated by published code from official data and carries full provenance. Automated checks compare our calculations with official values where they exist. Each publication states its review tier (draft, preprint, reviewed, peer-reviewed). **No publication has had external scientific review yet.** The public site contains no AI features.

Errors can be reported as GitHub issues. Corrections are logged publicly.
