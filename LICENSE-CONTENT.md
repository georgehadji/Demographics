This file does not repeat them.

Rules that follow from those terms:

- Every release and every chart or map carries the `attribution` line of each source it uses, and meets the conditions in that licence's `notes` (for example, stating modifications).
- Where a source's `commercial_reuse` is `false`, the material taken from it is not covered by CC BY 4.0; only the project's own contribution is. In practice this applies to map boundary geometry.
- Each release lists the source terms that apply to it.
