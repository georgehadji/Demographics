# charts/src/

Code of the chart library.

| File | What it does |
|---|---|
| `chart.js` | `compose`: turns a figure function into a chart type returning figure, data table, alt text and CSV; input checks, footer (source, dataset, vintage, nature) and the Greek and English chart text |
| `grammar.js` | `style(nature, status)`: the epistemic grammar (PROPOSAL §7A) as token names: dash, bands, scenario hue, hollow marker, gap |
| `line.js` | `line`: line chart over time, focus in the accent, comparators neutral, labels on the lines, segments per nature and break in series |
