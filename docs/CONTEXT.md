# docs/

Project documents, mostly in Greek.

| File | What it does |
|---|---|
| `decisions` | Architecture decision records: see `decisions/CONTEXT.md` |
| `IMPLEMENTATION-PLAN.md` | Steps of Phases 0–2, one pull request each, with the check that closes each step |
| `landscape.md` | Scan of existing Greek and European demographic observatories and possible reviewers, each claim graded |
| `proposal-v1-original.md` | The original proposal, kept unchanged |
| `PROPOSAL.md` | The authoritative plan: research programme, credibility rules, sources, indicators, projection model, design system, architecture, roadmap |
| `REVIEW.md` | Critique of the original proposal: claims checked and methodological issues (dated, not updated) |
| `spikes` | Time-boxed investigations: see `spikes/CONTEXT.md` |
