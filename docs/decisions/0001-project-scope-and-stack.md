# ADR 0001: Εύρος έργου και τεχνολογική βάση

- **Ημερομηνία:** 2026-09-28
- **Κατάσταση:** αποδεκτή

## Πλαίσιο

Μετά την κριτική της πρότασης v1 (`docs/REVIEW.md`), ο ιδιοκτήτης του έργου αποφάσισε ότι:

1. Όλη την υλοποίηση την κάνει το Claude.
2. Ο στόχος είναι η δημόσια αξιοπιστία.
3. Το έργο είναι έρευνα και δημοσίευση, έντονα στατιστικό, με υψηλού επιπέδου graphic design και σύγχρονη οπτικοποίηση δεδομένων.
4. Το έργο δεν είναι εμπορικό.

## Απόφαση

- **Εύρος:** αφαιρούνται όλα τα εμπορικά στοιχεία (billing, auth, API με quotas, white-label, έρευνα αγοράς). Προστίθενται ερευνητικό πρόγραμμα (R1–R7), μηχανισμοί αξιοπιστίας (επώνυμος υπεύθυνος, εξωτερικό review, δήλωση χρήσης AI) και design system ως κώδικας.
- **Αρχιτεκτονική:** αποκλειστικά στατική (A + C της v2). Η εναλλακτική B (full-stack) απορρίπτεται οριστικά.
- **Γλώσσα modelling:** Python. Η R χρησιμοποιείται μόνο στο CI για τα πακέτα πιθανοτικών προβολών του ΟΗΕ.
- **Γλώσσα δημοσίευσης:** observatory στα ελληνικά, μεθοδολογία και working papers σε ελληνικά και αγγλικά.

## Εναλλακτικές που εξετάστηκαν

| Επιλογή | Γιατί απορρίφθηκε |
|---|---|
| Full-stack με backend (v1) | Κόστος λειτουργίας και πολυπλοκότητα χωρίς όφελος για μη εμπορικό έργο |
| Μόνο R/Quarto | Η R είναι ισχυρότερη σε ειδικά δημογραφικά πακέτα, αλλά δύο οικοσυστήματα αυξάνουν την επιφάνεια λαθών. Επιπλέον, το CRAN δεν είναι προσβάσιμο από το τρέχον περιβάλλον ανάπτυξης. |
| Μόνο ελληνικά | Περιορίζει τον διεθνή επιστημονικό έλεγχο και τις αναφορές |

## Συνέπειες

- Ο κύριος μηχανισμός ποιότητας είναι τα αυτόματα tests και οι έλεγχοι αναπαραγωγής, γιατί ο συγγραφέας (Claude) δεν μπορεί να είναι ανεξάρτητος ελεγκτής του εαυτού του.
- Η αξιοπιστία εξαρτάται από εξωτερικούς ανθρώπους, τον υπεύθυνο έκδοσης και τους reviewers. Αυτό παραμένει ανοιχτό ερώτημα (PROPOSAL §12).
