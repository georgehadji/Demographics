# ADR 0002: Υπευθυνότητα, όνομα και άδειες

- **Ημερομηνία:** 2026-09-28
- **Κατάσταση:** αποδεκτή

## Απόφαση

1. **Υπεύθυνος έκδοσης:** Georgios-Chrysovalantis Chatzivantsidis. Υπογράφει και εγκρίνει κάθε δημοσίευση και είναι ο δημόσιος υπεύθυνος για τα αποτελέσματα.
2. **Εξωτερικός reviewer:** δεν υπάρχει προς το παρόν. Οι δημοσιεύσεις ακολουθούν τις βαθμίδες του PROPOSAL §1B και δεν παρουσιάζονται ως ελεγμένες πριν υπάρξει γραπτό εξωτερικό review.
3. **Όνομα εργασίας:** Demographer. Χωρίς δικό του domain· φιλοξενία στο GitHub Pages.
4. **Άδειες:** MIT για τον κώδικα, CC BY 4.0 για κείμενα, γραφήματα και παράγωγα δεδομένα, με την επιφύλαξη των όρων κάθε πηγής.

## Ρίσκα που καταγράφονται

- **Σύγκρουση ονόματος (VERIFIED):** το demographer.org δημοσιεύει ήδη σελίδες με δημογραφικά στοιχεία της Ελλάδας από ELSTAT, Eurostat και World Bank. Κίνδυνοι: σύγχυση αναγνωστών, χαμηλή ευρεσιμότητα και απόδοση των δικών μας αποτελεσμάτων σε τρίτους (ή αντίστροφα).
- **Σημασιολογικό ρίσκο (INFERENCE):** ένα έργο με όνομα «Demographer», χωρίς ανθρώπινο δημογράφο στην ομάδα και χωρίς εξωτερικό έλεγχο, μπορεί να διαβαστεί ως ισχυρισμός επαγγελματικής ιδιότητας. Αυτό λειτουργεί αντίθετα στον στόχο της αξιοπιστίας.
- **Μέτρο:** το όνομα θεωρείται προσωρινό. Η οριστική απόφαση λαμβάνεται πριν από την πρώτη δημόσια έκδοση (Φάση 2). Ο κώδικας δεν εξαρτάται από το όνομα: το Python package λέγεται `grpop`.
